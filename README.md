# 🌌 Acerca del proyecto

**Movie Streaming Website** es una plataforma multimedia desarrollada con Vue 3 enfocada en la exploración y reproducción de películas y series.

La aplicación ofrece una experiencia moderna e interactiva mediante:

- 🎬 Exploración multimedia
- 🔎 Búsqueda avanzada
- 🎤 Voice Search
- 🌐 Traducción integrada
- 🌙 Dark Mode
- 📺 Reproducción de episodios

El proyecto está diseñado para brindar una experiencia cinematográfica moderna y responsive.

# ⚡ Instalación

## 📋 Requisitos del sistema

- Node.js >= 18.x
- npm >= 10.x

---

## 1️⃣ Clonar repositorio

```bash
git clone https://github.com/isairey/PlataformaMultimediaVue.git
```

---

## 2️⃣ Entrar al proyecto

```bash
cd app
```

---

## 3️⃣ Instalar dependencias

```bash
npm install
```

---

## 4️⃣ Ejecutar aplicación

```bash
npm run serve
```

---
